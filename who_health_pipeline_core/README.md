# WHO Health Data Pipeline

This project implements an automated ETL pipeline to extract, validate, transform, and load health-related data from the **World Health Organization (WHO) API** into a PostgreSQL database using **Apache Airflow**. The processed data is then used to create visualizations and insights in **Power BI**.

## 🌐 Overview

The pipeline performs the following steps:

1. **Extract**: Downloads raw indicator datasets from the WHO API.
2. **Validate**: Applies data integrity checks and basic filtering.
3. **Transform**: Cleans, standardizes, and combines datasets, including filling missing values.
4. **Load**: Uploads the cleaned data to a PostgreSQL database for analysis.

## 📊 Dashboards

Power BI dashboards are built on top of the PostgreSQL tables generated by this pipeline. The focus areas are:

- **Life Expectancy**
- **Universal Health Coverage (UHC) Index**
- **Access to Safe Water and Sanitation**

Each indicator includes time-series and regional comparisons, with breakdowns by sex or area of residence where available.

## 🚀 Getting Started

### 1. Clone this repository

```bash
git clone https://github.com/your-username/who_health_pipeline.git
cd who_health_pipeline
```

### 2. Build and run the containers

```bash
docker-compose up --build
```

> ❗ **Important**: After the containers are built, you must manually initialize Airflow for the first time:
```bash
docker exec -it airflow-webserver airflow db init
docker exec -it airflow-webserver airflow users create     --username admin --password admin     --firstname Admin --lastname User     --role Admin --email admin@example.com
```

Then, restart the containers:
```bash
docker-compose down
docker-compose up
```

Airflow UI will be available at: [http://localhost:8080](http://localhost:8080)

### 3. Trigger the DAG

In the Airflow UI, unpause the `who_health_pipeline` DAG and trigger it manually (or wait for the next scheduled run).

## 📦 Environment Variables

These are set automatically in Docker, but if running locally, ensure the following are defined:

```env
POSTGRES_USER=airflow
POSTGRES_PASSWORD=airflow
POSTGRES_DB=who_db
POSTGRES_HOST=localhost
POSTGRES_PORT=5432
```

|----------|----------|-----------|-------|
| Life Expectancy | `WHOSIS_000001` | Sex | Includes high/low bounds |
| UHC Index (reported) | `UHC_INDEX_REPORTED` | None | Aggregate score |

## 🧪 Data Processing Logic

- Data is **renamed and standardized** for consistency.
- Where missing values exist in `urban`, `rural`, or `total`, **estimates are inferred** based on the other two values.
- Each row is assigned a composite primary key (`pk_country_year`).
- Pivoted tables allow better Power BI integration.

## 📌 Notes and Limitations

- Several initial indicators were not available via the WHO API and had to be replaced.
- Some countries or years may lack data, particularly for residence-based indicators.
- `extract_data.py` only downloads datasets confirmed to exist in the WHO public API.
