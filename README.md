# 🧠 Joao Abaca — Data Portfolio

Welcome to my data portfolio. I'm a biomedical engineer transitioning into data analytics and engineering. This repository showcases end-to-end projects focused on **data pipelines, modeling, validation, and dashboards**, using tools like **Airflow**, **DBT**, **Docker**, and **PostgreSQL**.

Each project simulates real-world data workflows and demonstrates my ability to automate processes, ensure data quality, and deliver insights for decision-making.

---

## 🚀 Projects

### 1. 🌍 WHO Health Data Analytics Dashboard
- **Tech stack:** Python, Airflow, Docker, Pandera, PostgreSQL, Power BI
- **Goal:** Build a full data pipeline using the WHO Global Health API to explore relationships between life expectancy, healthcare coverage, water, and sanitation across 180+ countries.
- **Highlights:**
  - Extracted, validated, and transformed health indicators
  - Automated pipeline orchestration with Airflow and Docker
  - Correlation analysis (Pearson r ≈ 0.7–0.85)
  - Interactive Power BI dashboard with policy-relevant insights
- 📁 [Go to Project](./who_health_pipeline/README.md) *(adjust path if needed)*

---

### 2. 🛍️ Shopify Sales Analytics with DBT & PostgreSQL
- **Tech stack:** PostgreSQL, DBT, Docker, Pandas, SQLAlchemy
- **Goal:** Transform raw Excel-based e-commerce data into a dimensional model using DBT, preparing it for business intelligence.
- **Highlights:**
  - Raw → staging → fact & dimension tables
  - 15+ automated tests using DBT `schema.yml`
  - Ready for Power BI or Streamlit dashboard
- 📁 [Go to Project](./shopify_dbt_pipeline/README.md)

---

### 3. 🧱 Crypto ETL Pipeline with Airflow & PostgreSQL
- **Tech stack:** Python, Airflow, Docker, Pandera, PostgreSQL, Pytest
- **Goal:** Automate the ETL of real-time cryptocurrency prices using the CoinGecko API.
- **Highlights:**
  - DAG orchestration with Airflow
  - Validation with Pandera
  - Containerized with Docker
  - Unit tests with Pytest
- 📁 [Go to Project](./crypto_etl_airflow/README.md)
