## 🚀 Projects

### 1. 🧱 Crypto ETL Pipeline with Airflow & PostgreSQL
- **Tech stack:** Python, Airflow, Docker, Pandera, PostgreSQL, Pytest
- **Goal:** Automate the extraction, validation, transformation, and loading of real-time cryptocurrency data from the CoinGecko API.
- **Highlights:**
  - Daily DAG orchestration with Airflow
  - Data validation with Pandera
  - Containerized with Docker
  - Tests implemented with Pytest
- 📁 [Go to Project](./crypto_etl_airflow/README.md)

### 2. 🛍️ Shopify Sales Analytics with DBT & PostgreSQL
- **Tech stack:** PostgreSQL, DBT, Docker, Pandas, SQLAlchemy
- **Goal:** Load and transform an e-commerce sales dataset using DBT, applying dimensional modeling and quality testing.
- **Highlights:**
